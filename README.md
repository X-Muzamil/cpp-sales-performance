# Sales Performance Evaluation System

This repository contains a C++ program that evaluates **monthly sales performance** using arrays and user-defined functions.  
The program demonstrates modular programming concepts such as input handling, average calculation, performance evaluation, comparison, and growth analysis.

## 📌 Features

1. **Input Function**  
   - Takes sales data for `n` months from the user.  
   - Stores values in an integer array.

2. **Display Function**  
   - Prints all sales values entered.

3. **Average Function**  
   - Calculates and returns the average sales.

4. **Performance Function**  
   - Evaluates performance based on average:  
     - Excellent (≥ 80)  
     - Good (≥ 60)  
     - Satisfactory (≥ 40)  
     - Poor (< 40)

5. **Comparison Function**  
   - Finds and displays the highest and lowest sales values.

6. **Growth Function**  
   - Counts how many months had sales above the average.
